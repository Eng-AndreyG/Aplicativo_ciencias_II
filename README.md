# Aplicativo Ciencias de la Computación II

Plataforma web educativa e interactiva (Universidad Distrital F.J.C.) que simula paso a paso y analiza la complejidad de todos los temas del syllabus.

**Uso:** abrir `index.html` en el navegador. No necesita servidor ni instalación.

## Estructura

| Archivo | Contenido |
|---|---|
| `index.html` | Estructura, barra lateral (4 módulos) y workspace unificado |
| `styles.css` | Paleta crema/durazno, grafos SVG, matrices, pestañas, alertas |
| `js/core.js` | Utilidades, logs, reproductor (Siguiente Paso / Automático / Reiniciar), catálogo de temas y complejidades, renderizador de árboles |
| `js/mod1_busquedas.js` | Búsquedas, cubetas dinámicas, funciones hash (decimal/binario), colisiones, árbol digital, residuos, Huffman, rejilla, árbol 2D |
| `js/mod2_arboles_indices.js` | BST, AVL, índices primario/secundario/multinivel, calculadora de accesos a disco |
| `js/graph_engine.js` | Modelo G = (S, A), editor interactivo de grafos, presets y algoritmos base |
| `js/mod3_grafos_caminos.js` | Inspector, Euler/Hamilton, operaciones, productos, centro/mediana, árboles de expansión, Bellman, Dijkstra, Floyd |
| `js/mod4_grafos_avanzados.js` | Circuitos y cortes, matrices, coloreado y polinomio cromático, independencia/dominación, pareamientos, envolventes |

La lista de pruebas para la sustentación está en [`SUSTENTACION.md`](SUSTENTACION.md).
